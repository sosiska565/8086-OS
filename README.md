# 8086-OS v<!--VERSION-->0.9.4-beta<!--/VERSION-->
---

**8086-OS** — это легкая операционная система, написанная на языках **C** и **ASM** и предназначенная для x86-совместимых систем. Несмотря на название, ОС разработана для 32-битных процессоров архитектуры x86 (начиная с i386)

>Внимание! 
>
>Эта операционная система разрабатывается исключительно в учебных и развлекательных целях. Она не является массовым продуктом и не гарантирует стабильной, безопасной работы, а также абсолютной безошибочности исходного кода. Используйте ее для изучения операционных систем. Запускайте на реальном железе на свой страх и риск, автор ничего не гарантирует!

---

## Требования и запуск

Самый быстрый способ собрать проект и протестировать его в эмуляторе **QEMU** — использовать команду:
```bash
make run
```
Она автоматически скомпилирует ядро, соберёт пользовательские программы, подготовит образы и запустит операционную систему. Для просмотра всех доступных команд сборки введите:
```bash
make help
```

#### Запуск в других виртуальных машинах

Вы можете протестировать 8086-OS в любом другом эмуляторе (например, VirtualBox). Для этого после сборки используйте готовые файлы в корневом каталоге:
- os.iso — загрузочный Live-CD образ.
- disk.img — тестовый образ жесткого диска (FAT32) со всем предустановленным пользовательским софтом и SDK.

>Важно: Перед началом сборки обязательно ознакомьтесь со списком необходимых пакетов в файле dependencies.txt.

#### Быстрый старт в Ubuntu / Debian

Установите зависимости и запустите ОС двумя командами:
```bash
sudo apt update && sudo apt install -y make gcc-multilib g++-multilib nasm dosfstools mtools grub-pc-bin grub-common xorriso qemu-system-x86 git

make run
```

Для упрощения развертывания окружения и исключения необходимости ручной установки тулчейна (gcc-multilib, nasm, xorriso и др.) в проекте предусмотрена поддержка контейнеризации через **Docker**.

Данный метод является рекомендуемым для разработчиков, использующих операционные системы macOS, Windows или дистрибутивы Linux, отличные от Arch Linux. Компиляция и сборка образов (os.iso и disk.img) происходят в изолированном контейнере, после чего готовый продукт автоматически запускается в локальном эмуляторе QEMU на хост-машине.

#### Запуск на Linux / macOS

Убедитесь, что демон Docker запущен и так же убедитесь, что у вас установлен **QEMU** на хост машине, после чего выполните скрипт автоматизации из корневой директории репозитория:
```bash
chmod +x ./docker-run.sh
./docker-run.sh
```

## Что в ней уже реализовано?

**Архитектура и управление памятью**
- 32-битный защищенный режим.
- Страничная организация памяти и поддержка виртуальной памяти.
- Собственный умный менеджер кучи с защитой от фрагментации.

**Многозадачность и процессы**
- Вытесняющая многозадачность на базе системного таймера.
- Загрузчик исполняемых файлов формата **ELF32**.
- Обработка POSIX-подобных сигналов.
- Межпроцессное взаимодействие: каналы и разделяемая память.

**Файловая система и хранилища**
- Абстракция Виртуальной Файловой Системы с поддержкой точек монтирования.
- Полноценный драйвер **FAT32**.
- Виртуальные интерфейсы `/dev` и `/proc` для взаимодействия с устройствами и получения информации о системе.
- Кэширование дисковых операций для ускорения чтения/записи.
- Поддержка загрузки Ramdisk через GRUB.

**Сетевой стек**
- Полноценная поддержка TCP/IPv4 на базе порта ядра **lwIP**.
- Встроенные клиенты DHCP и DNS.
- Реализация стандартных сокетов на уровне системных вызовов.

**Драйверы устройств**
- Сканирование и работа с шиной **PCI**.
- Драйверы дисков: современный **AHCI** и классический **ATA PIO**.
- Сетевой драйвер: **Realtek RTL8139**.
- Графическая подсистема: **VESA BIOS Extensions** с линейным кадровым буфером и двойной буферизацией.
- Периферия: мышь и клавиатура (PS/2), часы реального времени (RTC), системный динамик (PC Speaker).

**Интерфейс системных вызовов**
- Кастомное прерывание `0x80` для взаимодействия пространства пользователя (Ring 3) с ядром (Ring 0).

**Собственная библиотека для С программ**
- Возможность написания программ для **8086-OS** на языке **c**.

## Структура проекта

- `boot/` — код первичной загрузки, инициализация GDT и переход в 32-битный режим.
- `disk/` — файлы окружения и SDK, которые автоматически копируются в FAT32-образ диска.
- `drivers/` — драйверы аппаратных устройств.
- `fs/` — реализация виртуальной файловой системы и драйвер FAT32.
- `kernel/` — основной код ядра операционной системы.
- `system_apps/` — встроенные системные программы, которые компилируются вместе с ядром.
- `userland/apps/` — исходный код пользовательских приложений.
- `userland/lib/` — пользовательские библиотеки.

---

# Структура внутри ОС

- `/include/` - заголовочные файлы (.h) для разработки прикладного ПО и использования API системных вызовов.
- `/lib/` - статические или динамические объектные библиотеки, предоставляющие runtime-окружение для исполняемых файлов.
- `/path/` - директория поиска исполняемых файлов (аналог переменной $PATH); содержит бинарные образы, доступные для глобального вызова.
- `/wallpapers/` - директория ресурсов графического подсистемы; содержит медиа-контент для рендеринга в wm.elf.
- `/dev/` - точка монтирования виртуальной файловой системы устройств; обеспечивает абстрактный доступ к драйверам периферии.
- `/proc/` - псевдофайловая система ядра; предоставляет интерфейс для динамического получения телеметрии процессов и состояния системы.

# Основные пользовательские программы

>Внимание!
>
>Запуск приложений с графическим интерфейсом (GUI) требует активной сессии оконного менеджера (wm.elf). Попытка выполнения GUI-программ вне графического контекста может привести к некорректной работе системы.

#### Графические приложения (GUI)

- `activity.elf` - монитор системных ресурсов для отслеживания активных процессов в реальном времени.
- `browser.elf` - легковесный рендерер HTML-страниц; поддерживает протокол HTTPS, не выполняет CSS/JS.
- `code.elf` - интегрированный редактор исходного кода с базовыми функциями манипуляции текстом.
- `doom.elf` - порт игрового движка Doom.
- `finder.elf` - графический файловый менеджер.
- `wm.elf` - оконный менеджер; обеспечивает композицию рабочего стола и управление жизненным циклом окон.
- `gterm.elf` - графический терминал, предоставляющий виртуальный интерфейс TTY.
- `settings.elf` - централизованный интерфейс для настройки параметров операционной системы.

#### Консольные утилиты (CLI)

- `cat.elf` - конкатенирует и выводит содержимое указанного файла в stdout.
- `curl.elf` - утилита для передачи данных по сети; поддерживает различные сетевые протоколы.
- `eza.elf` - расширенная утилита для работы с директориями и файлами.
- `fetch.elf` - инструмент для вывода системной телеметрии (версия ядра, состояние оборудования, аптайм).
- `gcc.elf` - GNU Compiler Collection; стандартный инструментарий для компиляции исходного кода C.
- `ifconfig.elf` - утилита для настройки сетевых интерфейсов и мониторинга их состояния.
- `ls.elf` - выводит список содержимого директории.
- `lsblk.elf` - утилита для перечисления блочных устройств; отображает подключенные диски и разделы.
- `nslookup.elf` - сетевой инструмент для запросов к DNS-серверам и преобразования доменных имен.
- `ping.elf` - диагностическая утилита для проверки доступности узлов сети с помощью ICMP-запросов.
- `pkg.elf` - менеджер пакетов для установки, обновления и удаления программного обеспечения.
- `sh.elf` - командная оболочка; обеспечивает интерактивный интерфейс для выполнения команд. 
- `tcc.elf` - Tiny C Compiler; высокопроизводительный компилятор языка C.
